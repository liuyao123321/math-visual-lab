# 知数实验室

面向大学生的交互式数学答疑网站。它把分步解析、函数图像、错题复习和学习报告组织成一个完整学习闭环。

## 功能

- 三道无需网络或密钥的完整演示题：二次函数、导数与动态切线、定积分面积。
- DeepSeek 真实解析：求解、针对某一步重新讲解、生成相似练习。
- Plotly 交互图像与参数滑块，解析步骤和图层高亮联动。
- 浏览器本地错题集：错误原因、笔记、掌握状态和复习次数。
- 学习报告：掌握率、薄弱知识点和近七日学习节奏。
- 深浅主题、响应式三栏/移动标签页和键盘可访问控件。

## 本地运行

要求 Node.js 22.13 或更高版本。

    npm install
    npm run dev

浏览器打开终端显示的本地地址。生产构建：

    npm run build

运行测试：

    npm test

## DeepSeek 配置

打开网站的“设置”页面，输入 DeepSeek API Key。密钥存入浏览器 localStorage，请求时通过本站 /api/tutor 服务端代理转发，不会写入源码、错题记录或应用日志。

此方案仅适合课程演示。建议使用低额度、可随时撤销的专用密钥，不要在公共电脑保存。可通过环境变量 DEEPSEEK_MODEL 修改服务端默认模型，默认值为 deepseek-flash。

## 数据说明

- 错题：mathlab.mistakes.v1
- 用户设置：mathlab.settings.v1
- DeepSeek 密钥：mathlab.deepseek-key.v1

以上内容全部存储在当前浏览器。清除浏览器网站数据会同时清除这些记录。

## 3–5 分钟答辩演示

1. 首页说明项目目标：不仅给答案，还要展示推理和图像。
2. 打开“导数与极值”示例，依次点击步骤，展示曲线、极值点和动态切线。
3. 调整切点滑块，说明导数的几何意义。
4. 填写错误原因并收藏错题，在错题集中修改笔记和掌握状态。
5. 打开学习报告，展示掌握率和薄弱知识点统计。
6. 在设置页说明 DeepSeek 接口、服务端代理、结构化校验以及密钥安全边界。
7. 如已配置演示密钥，输入一道新题展示真实 AI 解析；若网络异常，继续使用三道离线示例完成演示。

## 主要目录

- app/：页面、路由和 /api/tutor 接口。
- components/：答疑工作台、Plotly 图像、错题、报告和设置界面。
- lib/：Zod 数据结构、示例题、数学表达式安全计算、本地存储与状态管理。

AI 解析可能出现错误，重要结论应结合教材、教师讲解或独立计算核对。
