# 知数实验室

面向大学生的交互式数学答疑网站。这个网站能把分步解析、函数图像、错题复习和学习报告组织成一个完整学习闭环。

## 功能

- 网站统计与反馈：用户通过顶部“问题反馈”提交问题，维护者在设置页进入“开发者控制台”，查看匿名 UV/PV、功能使用、AI 请求和反馈处理状态。本机运行 `npm run operations:setup` 初始化；密码保存在本机忽略的 `outputs/developer-access.txt`。SQLite 持久化与线上 D1 配置、统计口径见 [OPERATIONS.md](OPERATIONS.md)。

- 四道无需模型密钥的演示题：二次函数、导数与动态切线、定积分面积、三重积分四面体。
- 三维可视化：在智能答疑页点击“试用三重积分示例”，按步骤观察底面投影、斜面和完整积分区域。支持旋转、缩放、图层显隐，要求浏览器支持 WebGL。自定义题的可视化模式支持有限的 `z=f(x,y)` 曲面和可用嵌套上下限描述的有界立体；图像只是区域示意，不以网格估算代替解析积分。任意隐式曲面和分段区域暂不支持。
- DeepSeek 真实解析：求解、针对某一步重新讲解、生成相似练习和理解检查。
- RAG 课程知识辅助：42条有公开教材来源的导数/单调性/极值知识卡，BM25与本地BGE向量混合检索，分步引用及定理条件说明；独立教材检索无需密钥。运行与验收见 [RAG.md](RAG.md)。
- 顶部“课程知识检索”（`/knowledge`）：自主选择全部已收录教材或指定教材，选择保存后也用于启用知识库辅助的普通答疑。当前仅OpenStax微积分第一卷部分章节；更多教材以后录入，不伪造完整教材内容。原答疑页不再放置独立检索表单，辅助解题开关和引用结果保留。
- 上传PDF作为个人教材：本机提取选定页面 → 分页预览并核对 → 保存 → 选择个人教材检索。支持100 MB以内文字版及扫描版PDF；无文字层时可启用浏览器本机中英文OCR，不上传原图或调用付费AI。扫描公式需逐页核对，建议先试读5—10页。文字版不设固定页数上限，结束页留空读到最后一页；显示进度并可取消。单份提取文字最多150万字符、个人教材库总JSON最多180万字符，最多5份教材，仍受浏览器可用容量限制。原PDF不保存；摘录默认不发给AI，单独允许后仅发送文字题匹配的最多4段资料。整本书语义索引及云同步暂不支持。详见[RAG.md](RAG.md)。
- 可选的 AI 个性化辅导：按课程、水平、学习目标和讲解偏好调整策略。
- 提示优先、分步引导、完整解析三种辅导方式；分步模式在学生确认后再揭示下一步和最终答案。
- 同一步支持换种讲法、图像解释、基础补充、概念对比和简单例子。
- Plotly 交互图像、细粒度滑块与数值输入；支持播放/暂停、倍速和重置，以及手动添加/移除横纵辅助线。参数、公式、关键点和积分区域同步更新。
- 一题多解：三个内置示例提供人工核对的两种方法；自定义题由 DeepSeek 生成不同解法并对比适用条件。
- 浏览器本地错题集：错误原因、笔记、掌握状态和复习次数。
- 学习报告：掌握率、薄弱知识点、近七日学习节奏和可直接执行的个性化复习建议。
- 深浅主题、响应式三栏/移动标签页和键盘可访问控件。
- 专项模拟（`/practice`）：选择最多5道错题，生成3/5/8题，作答自动保存；交卷后显示参考答案，配置密钥时提供逐题 AI 反馈，并记录学习打卡。旧 `/learn` 自动跳转。
- 按题意选择可视化：简单直接计算不强行配图；固定函数和固定区间只保留必要静态示意图，不添加改变原题条件的滑块。原题明确要求变化的动态切线等保留交互。旧题解快照也采用同一规则，不改写保存数据。

## DeepSeek 配置

### 图片自动选择辅导方式（2026-10-17 本地更新）

首页和智能答疑共用普通图片入口，不再单独切换“手写过程辅导”。AI先区分图片内容：只有题目 → 普通答疑；包含学生作答（即使只有一步） → 核对转录 → 逐步评价 → 方向/方法/局部示范三级启发；无法区分 → 由学生选择。题干公式、手抄题目不应被当作学生过程。识别有误可改回普通答疑，重新输入或上传不需寻找另一入口。修改步骤使旧评价与提示失效，不默认展示完整答案；原错题、知识库和学习功能保留。

沿用现有DeepSeek代理，不新增模型服务。官方确认Flash支持图片，但本轮自动化与模拟接口通过不等于真实手写识别质量已验收。使用、模块、测试案例、隐私和待实测边界详见 [HANDWRITING.md](HANDWRITING.md)。本轮仅本地实现，未发布线上。

打开网站的“设置”页面，输入 DeepSeek API Key。密钥存入浏览器 localStorage，请求时通过本站 /api/tutor 服务端代理转发，不会写入源码、错题记录或应用日志。

首页仅保留紧凑的文字、上传照片、拍照输入，不再显示宣传标语、功能介绍或示例卡片；离线示例仍在智能答疑页。智能答疑页也支持直接输入题目、手机拍照或选择 JPG、PNG、WebP、GIF 图片（单张最大 8 MB）。原始图片仅用于当次 DeepSeek 图像识别请求，不写入浏览器存储或错题集；请求失败时保留输入，成功分类后清除。首页照片通过单次消费、5分钟有效的 sessionStorage 结果快照进入答疑页，避免重复调用；快照只包含经校验的题解或原始文字转录及分流判断，不含原图或密钥。

“AI 学习偏好”可在设置页关闭。关闭后，客户端不会向 `/api/tutor` 发送学习画像；开启时仅发送课程、水平、目标、讲解偏好、辅导方式，以及最多 3 个薄弱知识点、3 类高频错误和近 7 天练习数量。姓名、学号、完整错题、笔记和原始照片不进入该摘要。

注意：摘要以外，每次业务请求仍发送必要内容。AI 整理发送当前资料文本/扫描页；AI 出卷发送主动选择的错题题干、知识点和错误原因；AI 评价发送本次学生回答。仅点击对应 AI 操作时发送，不会自动上传所有本地记录。不要导入含隐私信息的试卷；AI 输出需要人工校对，`uncertain` 不等于判错。

此方案仅适合课程演示。建议使用低额度、可随时撤销的专用密钥，不要在公共电脑保存。可通过环境变量 DEEPSEEK_MODEL 修改服务端默认模型，默认值为 deepseek-flash。

### 题目核对与自动讲解

- 条件不足时显示交互式核对卡片：AI 对题意歧义生成2至4个候选项，用户也可“自己填写”。没有预选；所有必要项填完，核对将提交的补充内容，再点击“确认补充并继续解析”，才重新调用正常核对/求解流程。完整题继续自动解析，不强制额外确认。
- 模型提示禁止为缺失的具体函数、数值和上下限编造候选；这种情况使用自由输入。旧模型输出未提供选项时也有补充输入兜底。用户说明不确定不代表条件完整，模型必须再次核对；候选仍需用户按原题判断，不能视为数学事实。
- 未提交的选项和自由补充保存到当前标签页的答疑会话，返回不自动调用AI。补充不确定或新发现缺少条件时继续询问，不强行生成答案；确认后的照片题使用已识别文字和用户补充，不重发原图。

### 本地数据键

- 错题：mathlab.mistakes.v1
- 用户设置：mathlab.settings.v2（首次读取会自动迁移 v1 的主题与解析模式）
- 理解检查记录：mathlab.understanding-attempts.v1（仅保存题解 ID、知识点、判断状态与时间）
- DeepSeek 密钥：mathlab.deepseek-key.v1
- 复习中心：mathlab.learning.v1（计划、确认后的资料、模拟试卷及完整作答、学习打卡）。最多20份资料、10份测验、366个打卡日期；达到资料/测验上限时先确认再替换最早记录。
- 答疑会话：mathlab.solve-session.v1（sessionStorage，仅当前标签页的最新答疑；不含原图和密钥）

以上内容全部存储在当前浏览器；答疑会话使用 sessionStorage，其余上述记录使用 localStorage。清除浏览器网站数据会同时清除这些记录。

## 资料与离线能力边界

- 文件最多10 MB、文本最多20000字符；PDF最多30页，其中扫描页最多5页，超过限制需拆分。
- Word原生公式和图片可能无法提取；PDF上下标、分式可能乱序。必须先核对预览，识别不清的条件不能猜测。
- 每份资料最多20题，每题2000字符；原文件/图片不写入localStorage。资料只保存确认后的文本和知识点。
- 复习计划是可解释的本地规则，不冒充AI规划；知识地图前置关系由课程目录整理，掌握状态依据用户标记。
- 离线模拟卷只覆盖二次函数、导数与积分变式。无密钥交卷只展示参考答案，不伪造AI评价；其他知识点和自定义题解析需密钥。
- 参数实验展示当前参数的结论，原题解析和错题快照保持不变。四舍五入后的数值使用近似号。
- 导入演示文件：`public/demos/revision-sample.txt`、`public/demos/revision-sample.pdf`。

## 3–5 分钟答辩演示

1. 首页展示文字或照片输入入口；若没有演示密钥，进入智能答疑页选择离线示例。
2. 在设置页选择“分步引导”和偏好的讲解方式，再打开“导数与极值”示例。
3. 点击“我理解了，继续”，说明最终答案不会提前泄露；固定二次函数没有任意改变常数项的动画。
4. 调整切点滑块，说明导数的几何意义；演示“结合图像”或“补基础”的多角度讲解。
5. 填写错误原因并收藏错题，在错题集中修改笔记和掌握状态。
6. 打开学习报告，展示掌握率、薄弱知识点和个性化复习入口。
7. 如已配置演示密钥，生成一道理解检查并提交回答；说明检查结果不会自动标记掌握。
8. 说明 DeepSeek 服务端代理、结构化校验、有限学习摘要和密钥安全边界。若网络异常，使用三道离线示例完成演示。

创新版演示：进入“专项模拟” → 根据已收藏错题生成3题离线卷 → 作答交卷 → 查看参考答案与学习打卡。AI 多解、AI 出卷和逐题评价只在已配置专用演示密钥时演示。
