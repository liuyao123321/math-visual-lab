## 交互规则

- 搜索覆盖题目、题型、知识点、笔记、错因，与时间／科目／难度／错因／掌握状态取交集。过滤选项由现有记录生成；空科目、空难度、空错因分别呈现为「未分类」「未标注」「未填写」。
- 时间按本地日历计算：今天、最近 7 天、最近 30 天，包含起始日且排除明日。无效时间不匹配时间过滤，收藏日期显示「时间未记录」。
- 默认按收藏时间最新在前；另支持最早、最近练习、练习次数、难度升降序。缺失／无效时间及未知难度置后，同值按收藏时间与 ID 稳定排序。清除过滤保留排序，不修改原始数组。
- 点题目或更多菜单打开详情；查看详情不增加练习次数。再次练习通过已有 `/solve?mistake=…` 路径进入工作台。
- 错因、笔记、掌握状态自动保存。失败时原记录不变，草稿在本页保留，关闭后重开可继续；重试或后续成功编辑保存全部待保存字段。保存失败期间，详情中的再次练习入口禁用；离开或刷新前仍须复制未保存内容。
- 详情展示既有解析、知识依据及限制；保存图像在展开后加载；手写评价按稳定步骤 ID 对应，仅展示已展开等级的提示。这些内容来自保存记录，不发起新的 AI 请求。
- 删除必须确认；取消不改记录，失败保留记录并提示。关闭详情或确认框后恢复触发元素焦点；元素已消失时回到页面标题。空错题集与过滤无结果分别提供提示和入口。
