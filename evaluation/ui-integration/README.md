# 答疑界面与识别链路回归记录

日期：2026-10-20。范围：本地修改、验证，未发布线上。

## 已实现

- 全站共享首页纸白／墨色设计变量；深色为温和炭黑。标题使用编辑式衬线字体，表单与正文保持易读的系统字体，KaTeX 独立排版。卡片、按钮、图表与强调色使用同一套语义颜色。保留首页及其演示影片。
- 桌面答疑页为双栏。左侧题目栏在导航下方 sticky 停靠，内容过长时可在栏内滚动；右侧为连续的步骤解析、必要图像、反馈与练习收藏。手机使用“题目／解析”两区切换。
- 每步只显示其关联图层及相关参数，早期步骤不展示后续关键点、面积标签或最终答案读数。不为没有图像配置的题目新增图像。固定题条件没有无关参数滑块。辅助线工具保留，默认折叠。
- 每步独立保存困惑和讲解，仅保留“换种讲法／结合图像／补基础”。修改困惑后废弃旧讲解，取消或忽略迟到的响应。页面往返、刷新恢复文字及反馈，不自动重复调用模型。

## 识别问题与修复

1. 教材辅助原先会因选中了未授权／不可用的个人 PDF，或纯图片题无法匹配个人 PDF 而在前端直接抛错，导致模型根本收不到题目。现改为明确提示本次跳过可选检索，并继续正常答疑；不改变教材授权，不发送未授权摘录。
2. 图片读取期间禁止提交；使用选择序号防止旧图片读取完成后覆盖新选择，也不会清空读取期间新输入的补充文字。支持将图片粘贴到题目输入框，支持同一文件重新选择。
3. 手机图片没有 MIME 时，可根据受支持的扩展名规范化 MIME；空文件、超限文件、错误格式、读取异常仍明确报错。不把任意文件当成可识别图片。
4. 文字输入与接口的 2000 字限制对齐，支持 Ctrl／Cmd + Enter 提交。公式仍由安全渲染模块处理。

## 浏览器与自动化验证

- 桌面：两栏布局；右侧滚动时左栏停靠于导航下方（约128px）。导数示例第一步无切点滑块，后续切线步骤才出现相关参数。
- 浅色：公式不再使用深蓝底，知识检索页面、步骤图像与反馈控件符合统一配色。
- 深色：公式、坐标与反馈内容可读。测试后恢复用户原有“跟随系统”设置，恢复浏览器默认尺寸。
- 手机390×844：题目／解析切换可用；正常加载与标签往返后正文宽375px，未超过390px视口。对窗口改变时Plotly短暂沿用旧宽度，补充了容器最大宽度与裁切约束。
- 全量 Vitest：39文件、286测试通过。涵盖原有API、拍照路由、手写流程、公式、错题、教材、设置与新增逐步辅导测试。涉及模型返回的自动化用例是模拟接口，不作为真实识别质量证明。
- 新增／扩展测试：图片空MIME、格式/大小校验、读取期间提交保护、旧读取覆盖防护、每步参数与图层隔离、三类选项、特定步骤请求、讲解迟到响应、反馈独立保存及恢复。
- TypeScript检查通过；本轮涉及核心模块的ESLint通过；生产构建通过。构建仍有大分包提示和vinext路由静态分类提示，不影响成功构建。既有KaTeX上标字符测试会输出字体度量提示，测试通过。

## 核心模块

- `app/globals.css`：统一视觉变量及双栏停靠布局。
- `components/solve-workspace.tsx`：答疑流程、图片输入与每步反馈状态。
- `components/step-tutoring-panel.tsx`：每步独立讲解、取消和异常反馈。
- `components/step-visualization.tsx`、`lib/step-visualization.ts`：限定当前步骤的图层／参数。
- `components/visual-experiment.tsx`、`components/math-plot.tsx`：嵌入式绘图、主题色、尺寸约束。
- `lib/question-photo.ts`：上传校验及读取规范化。
- `lib/tutor-client.ts`：可选教材检索的安全降级，不改授权。
- `lib/solve-session.ts`：兼容原会话的逐步反馈恢复。

## 已知边界

- 没有更换模型、接入新服务、发布线上或新增长期保存的错题。
- 真实测试只覆盖一题的文字、清晰图片及定向讲解，不声称所有笔迹识别均可靠。模糊／复杂手写仍需核对；相关失败、歧义路由主要由已有模拟API回归覆盖。
- 原图仍不写入会话存储；返回时若图片尚未完成识别，需要重新选择，文字与已完成反馈可恢复。
- 图像仅在选定可视化讲解且存在有效步骤图层时展示，不将所有题目强制变成动画。
